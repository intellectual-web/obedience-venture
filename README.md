# Obedience Ventures website refresh

This is a refreshed static website package for GitHub Pages.

## Included
- `index.html` — responsive homepage with about, services, product interests, partnership section and enquiry form.
- `styles.css` — green, gold and cream brand styling; mobile responsive layout.
- `script.js` — mobile navigation and WhatsApp enquiry message.
- `assets/obedience-ventures-logo.png` — logo concept generated for Obedience Ventures.
- `BUSINESS_AND_GROWTH_PLAN.md` — staged business development and international opportunities plan.

## Before publishing
1. Check the phone number in `script.js` and the contact section in `index.html`. It is currently set to 08088435813 based on the existing website.
2. Confirm which products and services are actually available. The site deliberately describes these as areas of focus and asks visitors to confirm availability; remove any service that you do not provide.
3. Confirm the legal business name, registration status, and any claims about certifications before adding them.
4. Replace the logo file if you later create a transparent-background SVG/PNG version. The current generated logo is a PNG concept.
5. Test the WhatsApp button on a phone before launch.

## Publish on GitHub Pages
1. Open the repository for `intellectual-web/obedience-ventures` on GitHub.
2. Download and unzip this package on your device.
3. Upload/replace `index.html`, `styles.css`, `script.js`, the `assets` folder and `BUSINESS_AND_GROWTH_PLAN.md` in the repository root. Keep any other project files you need.
4. Commit the changes to the branch/folder configured for GitHub Pages.
5. Wait for the Pages deployment to finish, then open the live site and test navigation, logo, mobile layout and WhatsApp enquiry.

This package has not been uploaded to GitHub and does not itself change the live website.
